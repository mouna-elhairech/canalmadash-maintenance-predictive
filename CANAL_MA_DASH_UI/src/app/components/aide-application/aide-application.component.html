Aide application CanalMaDash

Cette page explique les principales parties de l application et le role de chaque module dans la gestion maintenance.

Objectif

Centraliser les donnees machines, suivre les demandes, enregistrer les interventions et exploiter les indicateurs.

Logique generale

Machine -> Demande -> Intervention -> Pieces -> Indicateurs -> Rapport.

Utilisation

Commencer par creer les machines, definir les types, puis suivre les demandes et interventions.
